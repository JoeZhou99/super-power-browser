# 运营配置后台

独立项目位于同级 `../super-power-browser-admin`，基于 `youlaitech/vue3-element-admin` 精简。客户工作台与运营后台共用 Java API 和数据库，但使用独立账号、会话与权限边界；客户企业所有者不具备修改全平台配置的权限。

## 首期范围

| 配置 | 客户端使用位置 | 管理方式 |
| --- | --- | --- |
| 时区 | 店铺浏览器环境 → 高级设置 → 时区 | IANA 标识、显示名称、启停、排序，支持搜索 |
| 语言 | 店铺浏览器环境 → 语言 | 语言代码、显示名称、启停、排序 |
| 窗口尺寸 | 店铺浏览器环境 → 窗口尺寸 | 宽x高、显示名称、启停、排序 |
| 环境默认值 | 新建店铺、导入、未复制指纹的复制操作、恢复默认 | 从三个启用字典中选择 |
| 平台站点 | 创建店铺的平台/站点选择器 | 分类、平台、站点、入口网址、启停、排序 |

旧版时区通过 `sundry/getInfoByKey?key=timezone_list` 下发，平台通过站点树接口下发；旧版语言与分辨率自身仍含本地常量。新项目统一提供 `GET /api/browser-config`，平台延用已有 `GET /api/platform-sites`，运营后台通过 `/api/admin/configs/{key}` 维护。

协议类型、指纹执行模式、内核可运行能力、供应商套餐和支付渠道继续由对应代码或专用服务管理，避免配置出实际无法执行的功能。

## 数据与兼容

V20 新增配置文档、分组/全局版本、修改记录、运营账号及会话。首次初始化提供 Java 时区库的时区、常用语言、常用窗口尺寸；默认仍为 `Asia/Shanghai`、`zh-CN`、`1920x1080`。初始化只补缺失组，不覆盖已发布配置；平台直接维护已有 `platform_site` 数据。

客户端每次打开编辑器、恢复默认及导入时重新读取配置。请求失败会提示重试，新建保存等待配置加载成功；编辑旧店铺时保留已保存的合法值，已停用/未列出的值作为“当前值”回显。后台修改默认值不会直接修改既有店铺，平台入口调整也不覆盖旧店铺保存的网址。

保存采用分组版本校验，过期版本返回 409，防止覆盖其他管理员的修改。默认项必须启用，所有列表至少保留一项；平台现有 ID 不可删除。配置更新和修改记录同事务写入。

## 启动

客户端和后端仍使用主项目原启动方式。首次本地运营账号通过 `./start-preview.ps1 -BackendOnly -EnableOperations` 初始化，凭据保存在 `.local-preview/operations-access.json`。启动前需完成新后端构建；已经运行的旧进程需要升级重启后加载 V20 与运营账号。

在独立后台目录执行 `npm ci`、`npm run build`、`./start-preview.ps1`，访问 `http://127.0.0.1:3200`。生产初始化使用 `OPS_ADMIN_USERNAME` 和 `OPS_ADMIN_PASSWORD` 环境变量，具体部署与操作说明见独立后台 README。
