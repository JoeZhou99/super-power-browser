# SuperPower Browser 功能与部署状态

## 当前组成

Web 管理界面、Electron 桌面、Java API 与 Worker 分别维护构建入口。Windows x64 店铺浏览器使用 Chromium 144.0.7559.132；环境助手和账号助手随桌面发布。SuperPower AI 提供本机执行、技能和 SQLite 会话，模型及技能商店由后端提供。

## 已接入功能

| 范围 | 当前能力 |
| --- | --- |
| 账号与权限 | 登录会话、成员、角色、功能权限和店铺授权；服务端每次请求校验权限 |
| 店铺管理 | 创建、编辑、复制、设备绑定、授权、回收、操作日志及表格导入导出 |
| 设备管理 | 平台、专享及自有设备；代理检测、批量导入编辑、回收及自动续费设置 |
| 费用管理 | 报价、订单、人民币余额和账本；支付及设备交付通过外部适配器接入 |
| 桌面运行 | 内核按需下载和校验、下载取消与续传、店铺启动与关闭、窗口恢复、消息提示 |
| 内置插件 | 环境检查、代理、账号、Cookie、书签、Passkey、访问规则及表单辅助 |
| AI 工作区 | 聊天、附件、审批、店铺任务、技能、本地定时任务、自有及官方模型、套餐和用量 |

## 仍需接入与验收

- 正式支付商户、设备供应商、模型上游及相关运营配置需要按部署环境接入；本机预览不代表这些外部服务已上线。
- 生产 MySQL、私有 S3、HTTPS 服务及安装包发布需要在目标部署环境验收。
- 第三方插件市场、整个浏览器配置目录的云端同步、供应商备用线路尚未完整接通。Cookie、书签及 Passkey 同步不等同于完整配置目录同步。
- 跨客户端单人占用、Firefox、完整员工网页元素规则及白名单审批仍需实现。
- 部分高级筛选、日志时间筛选、批量续费和平台站点目录仍需完善。手机号、微信和邮箱绑定依赖验证服务。
- 当前内核的各平台账号填充、真实 Passkey 注册与认证、权限撤销后的浏览器关闭、指纹跨重启稳定性需要专项实机验收。

## 数据与运行边界

语言和时区支持自定义或按代理出口匹配，时区也可使用本地系统值；选择匹配 IP 时在下次启动前解析，换代理不重置固定指纹标识或浏览数据。行为对比与验证边界见 [代理切换与指纹](代理切换与指纹.md)。窗口尺寸控制浏览器窗口，不能等同于伪装显示器尺寸。店铺内核版本必须已发布，已有店铺不会自动切换版本。二进制摘要改变时，客户端拒绝静默替换已绑定的指纹身份。

桌面定期复核店铺权限，API 在权限撤销后的请求中拒绝访问。店铺永久删除目前删除服务端记录并保留本机浏览数据；设备回收不等于已向供应商释放租用资源。生产环境应明确数据清理、资源释放和失败订单补偿流程。
