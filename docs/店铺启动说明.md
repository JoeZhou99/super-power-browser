# 店铺启动说明

1. 管理页面通过 Electron preload 调用 `openBrowser(environmentId)`。
2. 桌面从后端取得启动配置，校验账号、店铺权限、设备和已发布的内核版本。
3. 校验并按需下载内核，支持共享下载、取消和断点续传。
4. 为店铺签发插件会话，启动本机代理与鉴权 WebSocket，将两个内置插件部署到该店铺的独立目录。
5. 生成启动配置和固定的指纹身份，通过 Chromium 原生参数启动浏览器。
6. 插件读取当前店铺配置并连接桌面，完成公网出口和 UA 检查；检查通过后按打开方式进入店铺页面。

浏览器进程运行与环境检测成功是两个状态。检测失败时保留检测页并提示原因，用户可重新检测。已经运行的店铺再次打开时复用进程；“显示浏览器窗口”可恢复窗口。

关闭店铺会回收代理、WebSocket 和窗口资源，撤销插件会话并清除临时启动密钥，保留浏览数据。退出客户端会取消待启动任务并关闭运行中的店铺。

运行数据位于 `{dataPath}/UserFile/independent/{shopId}/{version}`。启动诊断保存在店铺目录的 `runtime-diagnostics.json`，不记录令牌、账号密码或 Cookie。

详细配置见 [插件接入说明](../super-power-browser-plugins/docs/integration.md) 和 [内核说明](../super-power-browser-kernel/README.md)。功能限制见 [功能与部署状态](功能与部署状态.md)。
