# 企业与成员管理

## 注册与开户

登录页支持直接注册：填写用户名、密码、确认密码即可，注册成功自动登录。无需填写企业资料、短信验证码或设备认证。每次注册独立建立企业、默认部门、企业所有者、三类预置角色及零余额钱包，数据按企业隔离。

用户名为 3–80 个非空白字符，全局唯一。密码至少 12 个字符，UTF-8 编码不超过 72 字节。已有的修改密码、管理员重置成员密码和登录会话撤销继续可用。暂不提供短信登录、公开找回密码、多企业切换或企业所有权转让。

## 部门与角色

本版采用平级部门。企业所有者和拥有成员管理权限的超级管理员可以新增、改名、删除空部门；默认部门不可删除。存在成员或待审核申请的部门需先完成处理。

每个部门预置三类角色，功能权限可以调整。角色所属部门固定，成员只能绑定其所在部门的角色，多角色权限取并集、管理级别取启用角色的最高级别。

| 身份 | 资源范围 | 成员管理范围 |
| --- | --- | --- |
| 普通成员 | 本人创建或明确授权的店铺、相关设备与代理 | 无管理权 |
| 管理员 | 本部门资源及明确授权资源 | 本部门普通成员 |
| 超级管理员 | 企业全部店铺、设备与代理 | 各部门的管理员和普通成员 |
| 企业所有者 | 企业全部资源 | 可管理全部非所有者成员，含超级管理员 |

资源范围和功能权限分别校验。获得某种管理级别仍需相应功能权限；管理员不能授予自身没有的权限、调整同级/上级成员，或修改自己的角色、状态。所有者的资料与密码在账号设置中修改。

仅保留现有业务需要的 20 项功能权限：AI 使用/订购；店铺查看、创建、编辑、打开、删除、导出、授权；设备与代理查看、编辑、购买、续费、导出；余额查看、充值；订单查看、导出；成员管理、角色管理。设备/代理共用权限，不迁移旧版设备认证、登录时间限制等功能。

成员转部门时重新选择目标部门角色，原登录会话失效，旧邀请链接撤销。成员创建的资源随其部门归属变化；明确的店铺授权仍保留，管理员可手动撤销。

## 邀请与审核

管理员选择部门生成有效期 7 天的邀请链接，也可提前撤销。申请人通过链接填写用户名、姓名、密码及可选联系电话，提交后等待审核；待审核期间不能登录。审核通过时指定部门内角色，拒绝时记录原因。申请密码只保存 BCrypt 摘要，不向审核人员返回；通过或拒绝后清除申请中的摘要。

同一企业、同一用户名不能重复提交待审核申请。批准时再次校验用户名是否被占用，审核状态和成员创建在同一事务中提交。邀请人的权限、部门或账号状态变化也会使旧链接失效。

分享链接默认使用当前网页地址。正式部署可在 Web 构建时设置 `VITE_PUBLIC_APP_URL=https://你的公开访问域名`；本机预览生成的 localhost/127.0.0.1 链接仅用于本机验收，跨电脑邀请须使用可访问的公开网页地址。

## 停用、删除与移交

沿用旧版先停用再删除的流程。停用立即撤销登录及插件会话。删除前展示该成员名下店铺和设备数量（包含回收站），有资源时必须指定启用中的同企业接收人；部门管理员只能在本部门操作。

删除后清理成员角色、店铺授权、会话与邀请，将资源转交给接收人。历史订单和操作记录保留；成员记录被标记为已删除并从成员列表隐藏，不能恢复登录，原用户名不能重新使用。离职成员的自动续费授权停止，不自动转给接收人。成员删除后才完成交付的已购设备归企业所有者，且不开启自动续费；仅停用时保留原设备归属，同样不新增自动续费授权。

## 升级与验证

V19 为已有企业建立默认部门并保留旧成员、角色名称、功能权限及绑定。旧版 `member_type` 只用于显示，新版它会影响资源范围，因此迁移将旧角色按普通成员范围保留，原类型记录于 `legacy_member_type`。企业所有者可在升级后明确分配新的部门管理员/超级管理员角色；不会因升级自动扩大旧账号的资源访问范围。

自动化测试覆盖独立企业注册与回滚、迁移兼容、部门/企业隔离、越级操作、申请批准/拒绝/重复审核、邀请失效、成员调部门、会话撤销、停用后删除和资源移交、延迟设备交付。
