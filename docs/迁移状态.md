# 本版迁移状态

## 当前独立内核状态（2026-11-05）

当前使用自有 Electron、开源补丁 Chromium 144 和插件 0.3.1，启动不再读取旧站斧内核、helper、授权或 Electron。内核元数据在数据库，ZIP 当前为本地存储，可配置私有 S3；生产 MySQL 和真实云桶尚未验收。任务栏颜色/编号配置已按用户要求移除，补齐了 WebSocket 白名单、完整版本 UA、真实闪烁和提示音、客户端退出分派、启动/下载取消及发布版本校验。

本次 Node 6 项、Java 8 项测试及 Web/桌面/插件构建检查通过；独立 144 的临时 profile 完成实际启动、插件连接、检测、闪烁/提示音、复用和关闭。详见 [旧版对照审查](旧版对照审查-2026-11-05.md) 和 [当前内核说明](../super-power-browser-kernel/README.md)。仍不能认定全部原生指纹、第三方插件市场、完整缓存云同步及备用线路已等价迁移。

## 接入时需要提供的资料

内核维护方：正式分发与后续升级仍需匹配目标版本的原生 SDK、协议及授权绑定资料。当前已利用本机合法运行环境接通 137 内核。插件核心业务接口已转接新后端；第三方插件分发、完整浏览器缓存上传和供应商备用线路仍需各自的正式服务。

支付方：新商户标识、密钥或证书、可用通道、下单／查单／关单协议、回调验签规则与测试环境。`PaymentGateway` 返回的支付状态必须来自供应商验证结果；校验商户、订单、币种和金额，真实支付迟到回调也须记账。当前查单轮询覆盖近七天待确认订单，生产对账范围和关单规则需按正式通道补齐。

设备供应方：专区／平台／地域／套餐清单，明确的 `class_id → ipType` 映射，CNY 价格、期限、库存规则，购买／续费／加速的幂等键和查询接口。`DeviceSupplier.deliver(orderId, snapshot)` 超时重试前必须先查证供应商原订单，不能重复创建资源。平台设备凭据需由正式交付返回，不能手工把自有设备伪装成平台设备。

## 与原版的差异及待完成项

本版已恢复 Excel 模板、文件上传和导出；自有设备兼容旧版 14 列 Excel 模板，按地址与端口更新或新增，也可按设备 ID 精确编辑。每批 30 行独立处理，每次最多 300 行，显示逐行错误。店铺管理已移除“导入新账号”，保留创建店铺中的批量导入。部门、优惠券、企业转账、两类分组、店铺转让及额外设备类型仍按约定排除。密码不随导出文件传递。

插件 0.2.5 起，自有设备也必须通过实际公网出口检测，取消旧版自有设备直接放行。Clash 的回环地址仅作为代理入口，出口获取失败会保留检测页、禁用打开店铺并支持重新检测。新桌面已补齐 localGeo，本地网络信息与代理出口独立采集。详见 [设备代理检测与自有设备编辑](设备代理检测与自有设备编辑.md)。初次检测地址选择不一致导致当前 Clash 被判失败；对照运行中的旧站斧后，已对齐公开检测地址，当前规则模式可返回公网 IP。

启动复核补齐窗口显示、首次 profile 插件启用和旧进程退出隔离，使用全新临时环境完成成功、失败、修复重试、关闭重开的 11 步实测。保留旧版 RBP 目录、加密配置、内核加载、桌面通信与检测后导航流程。已连接实际旧店铺读取页面及检测配置；Clash 规则模式使不同检测地址返回本机或代理公网 IP，不应将某一检测结果当作所有店铺目标的出口。详见 [店铺启动流程复核](店铺启动流程复核.md)。

新增账户资料、改密及会话剔除服务；成员／角色恢复搜索、状态、角色描述和类型、权限分栏、复制删除、绑定成员和成员侧店铺授权。成员类型只是分类，不隐式授予全部权限。首页使用原新手引导图标，保留创建店铺与购买设备两步。

仍未达到逐项原样迁移：平台站点目前为平台选择加地址输入，未接入原版站点目录；部分高级筛选、店铺日志的时间筛选和批量续费仍需继续对齐。Passkey 已通过本地响应夹具中的真实 WebAuthn 注册、保存、重开和认证；尚未提交真实平台登录。输入框锁定已接通；单人共同访问、Firefox、自动按 IP 匹配语言和时区仍未完成。记住密码、消息提示、字体、语音的原生效果已有专项验证，具体限制见缺口验收文档。手机号、微信和邮箱绑定缺少新验证服务，保留位置但不可提交。购买页已保留各字段分区与摘要，真实商品、库存、远程类型和配置选项须由新供应商返回。

语言和时区首期由用户明确填写，默认中文与 `Asia/Shanghai`；暂不提供没有真实出口 IP 数据支撑的自动推断。原“分辨率”已更名“窗口尺寸”，当前实测 screen 仍随宿主显示器。稳定 seed、Canvas、Audio、Client Rects、WebGL、字体与语音已完成 Windows 137 专项验证，不能扩展为所有内核和所有指纹维度均已验证。

桌面每 10 秒重新检查在线店铺访问权，服务端拒绝访问时尝试关闭已启动浏览器；此链路尚未通过真实内核验证，不能宣称已终止现有网页会话。新 API 本身在权限撤销后的下一次请求即拒绝访问。

永久删除目前删除新后端记录，保留本地 profile，不自动销毁登录态。设备回收同样不代表已向供应商释放租用资源。失败交付可在供应商适配接入阶段增加受控重试／退款补偿入口，本版不提供伪造交付或退款按钮。

店铺详情已恢复基础信息、详细信息和操作日志页签；复制恢复新名称及选择复制内容。复制后环境标识独立；选择复制设备或授权时仍检查对应权限。新操作日志只记录动作与必要标识，不写入账号或代理密码。
