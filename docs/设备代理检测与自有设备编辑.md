# 设备代理检测与自有设备编辑

2026-11-04，插件版本 0.2.6。

## 检测规则

用户上传的自有设备也是代理，不再沿用旧插件 `ip_type=2` 的直接放行分支。所有设备通过当前店铺的本地转发服务访问公网 IP 检测服务，转发服务使用该设备保存的代理协议、地址和凭据。代理检测不会降级为直连。

- 固定公网 IP：多个检测地址中至少一个实际出口与映射 IP（优先）或设备公网地址一致，沿用旧版任一匹配的判断。
- 动态代理：允许出口变化，但必须返回有效公网 IP。
- Clash 等本地入口、私网入口、域名代理：必须取得公网出口，127.0.0.1 等入口地址不能作为实际检测结果。
- 检测失败或固定 IP 不一致：设备检测、线路检测显示失败，自动跳转停止，“打开店铺”禁用；保留浏览器检测页，并可点击“重新检测”。
- 环境校验保留旧版 UA 判断，代理检测和环境校验同时通过才打开店铺。当前检测不等同于目标电商站点可用性或完整浏览器指纹检测。

“实际检测”展示取得的公网出口 IP；无法取得时展示“暂未获取”。“绑定设备”保留配置地址及填写的地域，地域为空不加括号。设备地域是用户配置值，不是出口国家的实时证明。

检测地址对齐运行中旧站斧的公开 HTTPS 服务：myip.ipip.net、lumtest.com/myip.json、ifconfig.me/ip，支持其文本及 JSON 格式，不调用旧厂商专有检测服务。规则代理可能对不同检测地址使用不同出口；设备“检测代理”会提示此情况。本地入口没有预期固定公网 IP 时，按配置顺序展示真实返回值。

“本地网络”在桌面端直连采集，使用旧版的选取方式：优先两个来源确认相同 IP／国家的结果，否则使用可用结果。国家显示中文，省市按服务返回值显示。直连数据仅用于本地网络展示，不作为代理检测成功依据。请求有整体超时和响应大小限制。

## 自有设备编辑

设备管理工具栏的“编辑自有设备”在各设备页签可见，打开“导入编辑自有设备”。沿用旧版下载模板、上传文件后确认、每批 30 行、累计成功／失败和逐行错误展示的流程，每次最多 300 行。

兼容旧 `importIpTemplate.xlsx` 的说明行、第二行表头、14 个字段；同时识别新项目此前的一行表头。按当前用户可访问的自有设备地址与端口查找：唯一匹配则更新，没有匹配则新增，多个匹配则提示逐台编辑。可提供设备 ID 精确编辑，仍检查权限及设备类型。密码留空保留原密码，不随设备列表导出。

每行独立事务，校验失败不影响其他有效行；错误显示原 Excel 行号。导入协议限 HTTP、HTTPS、SOCKS5。模板保留旧 SS/SSR 字段以兼容读取，填写这些尚未支持的参数会明确报错，不会静默丢弃。

列表中的“编辑”可以逐台修改名称、动态／静态、协议、地址、端口、地域、登录信息及映射信息。设备管理“检测代理”使用与店铺启动相同的出口检测逻辑。

店铺管理已移除“导入新账号”按钮，创建店铺中的批量导入仍保留。
