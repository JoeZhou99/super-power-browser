# 设备代理检测与自有设备编辑

## 检测规则

所有设备通过当前店铺的本地转发服务访问公网 IP 检测服务。转发服务使用设备保存的代理协议、地址和凭据；检测失败不会降级为直连。

- 固定公网 IP：检测地址返回的至少一个实际出口与映射 IP（优先）或设备公网地址一致。
- 动态代理：允许出口变化，但必须取得有效公网 IP。
- 本地、私网或域名入口：入口地址不能作为公网出口检测结果。
- 检测失败或固定 IP 不一致：显示失败，停止自动跳转，保留检测页并允许重新检测。
- 公网出口与 UA 校验均通过后打开店铺；检查结果不代表目标站点可用性或全部浏览器指纹均已验证。

“实际检测”展示公网出口 IP，无法取得时显示“暂未获取”。“绑定设备”的地域来自用户配置，不代表实时出口国家。检测服务支持 myip.ipip.net、lumtest.com/myip.json、ifconfig.me/ip 的文本及 JSON 响应。规则代理可能对各地址使用不同出口，设备检测会提示这种情况。

“本地网络”由桌面直连采集，优先选择两个来源确认一致的 IP／国家，否则使用可用结果。该数据只用于本地网络展示，不作为代理成功依据。请求具有超时和响应大小限制。

## 自有设备导入与编辑

设备管理的“编辑自有设备”打开导入对话框。下载模板、填写并上传后确认导入；每批处理 30 行，每次最多 300 行，显示累计成功数、失败数和原始 Excel 行号。

支持首行说明、第二行表头的 14 字段模板，也识别单行表头。按当前用户可访问的自有设备地址与端口查找：唯一匹配则更新，无匹配则新增，多个匹配则提示逐台编辑。可提供设备 ID 精确编辑，仍检查权限及设备类型。密码留空保留原密码，不随列表导出。

每行独立事务，某一行失败不影响其他有效行。支持 HTTP、HTTPS、SOCKS5。SS/SSR 字段可被识别，但填写尚未支持的协议参数会明确报错。

列表中的“编辑”可逐台修改名称、动态／静态、协议、地址、端口、地域、登录信息及映射信息。“检测代理”与店铺启动共用出口检测逻辑。

店铺创建支持批量导入。完整启动链路见 [店铺启动说明](店铺启动说明.md)。
