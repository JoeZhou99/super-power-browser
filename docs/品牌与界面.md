# SuperPower 品牌与桌面界面

更新日期：2026-11-04。

产品展示名称统一使用 **SuperPower Browser**，新图标为蓝色圆角底上的白色 S。保留原有蓝色导航和侧栏布局，去掉工作区顶部蓝线，新增与界面配色一致的窗口标题栏，使用系统原生的最小化、最大化及关闭按钮。

登录页按扣除标题栏后的可用高度布局。1440×940、1366×768、1100×720 三种窗口尺寸下，登录表单和底部说明完整可见，页面没有横向或纵向滚动条。

## 图标应用位置

- 桌面窗口、Windows 任务栏和 Windows 安装包。
- 店铺浏览器窗口与任务栏；窗口标题带有 `SuperPower` 后缀。
- 登录页、侧栏、网页 favicon。
- 环境助手和账号助手的工具栏图标、扩展名称、检测页品牌标识及 favicon。

`branding/mark.svg`、`wordmark.svg`、PNG 和多尺寸 ICO 由本项目绘制。运行 `powershell -ExecutionPolicy Bypass -File scripts/generate-brand-assets.ps1` 可重新生成图标并同步 Web 公共资源。随后分别构建 Web 与桌面项目；桌面构建会同步品牌资源并生成新的插件 ZIP。

店铺浏览器启动前将图标复制到该店铺独立目录的 `superpower.ico`，通过内核支持的 `app_logo`、`icon`、`outside_icon` 字段配置。更改图标后需要重新打开店铺才能更新原生窗口图标，不修改内核可执行文件。

插件的品牌替换通过 `super-power-browser-plugins/lib/branding.mjs` 在构建阶段处理，仅作用于新项目模式。原始插件参考代码、来源注释和第三方归属信息保留；兼容协议所需的内核文件名、标识及插件目录名仍沿用既有协议。视觉品牌更新不代表已替换底层内核或完成所有插件功能的独立重写。
