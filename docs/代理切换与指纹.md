# 代理切换与指纹

核对日期：2026-11-11。范围为历史客户端可见流程与新项目当前实现，不代表两个不同内核的原生指纹算法相同。

## 新旧行为

| 操作/配置 | 旧版可见流程 | 新项目 |
| --- | --- | --- |
| 换绑代理、修改代理地址 | 换绑请求只传店铺和设备；打开时读取店铺的 `fp_magic` | 保留店铺的 `fingerprint_seed`、指纹设置与浏览器目录 |
| 语言跟随 IP | 每次开店按设备 IP 地区查国家语言表 | 每次开店通过本次代理实际出口解析国家，使用相同语言顺序 |
| 时区匹配 IP | 每次开店取设备地区信息的时区 | 每次开店从代理出口地区信息解析 IANA 时区 |
| 自定义语言、时区 | 自定义值优先 | 保留自定义值，不因换 IP 覆盖 |
| 本地时区 | 传空时区，让内核使用系统时区 | 启动时解析当前桌面系统时区 |
| 浏览器已经打开时切换备用线路/出口漂移 | 客户端切线没有重建打开参数 | 不重设运行中的指纹或语言/时区；关闭重开后重新解析 |

旧版依据：`旧版网页仓库/src/utils/mall.ts` 中 `getBrowserLanguage()`、打开参数中的 `fpMagic`，`src/utils/mallTimezone.ts` 中 `resolveMallTimezone()`，以及旧桌面 `旧版客户端桥接脚本` 的 `environment_key` / `time_zone` 映射。旧服务端不在这两个客户端项目内，不能据此断言其所有换绑场景都不会修改 `fp_magic`；旧客户端缺少该值时会生成新的 UUID。

旧版语言表来自 `src/constants/index.ts` 的 `ACCEPT_LANGUAGE_MAPPING`，并非远程字典。国家和时区信息来自设备资料或 IP 查询接口。新项目复制了 235 项语言映射，按旧版去掉 `;q=` 权重，保留原顺序。

## 配置与启动

- `language: "auto"`（兼容 `languageMode: "ip"`）表示语言跟随 IP；`timezone: "auto"` 表示时区跟随 IP；`timezone: "__local__"` 表示本地时区。
- 新建、恢复默认仍遵循运营后台的默认值。已有店铺、自定义值与指纹标识不会因升级或运营默认值改变而被重写。
- 语言或时区跟随 IP 时，出口地区解析在启动内核前完成，并复用同一次出口检测给首个检查页面。自定义模式不增加这项等待。恢复首选线路后重新查询，避免使用原线路的地区。
- 所有地区查询经过店铺代理，不使用桌面的本机公网出口，不跨店铺缓存地区。只返回 IP、没有所需国家/时区的响应不能作为自动匹配成功。
- 无法取得所需地区信息时提示重试或设置自定义值；不会悄悄使用本机时区或旧线路地区。固定代理的实际出口匹配检查继续生效。
- 更换代理地址或绑定设备在下次启动时生效。跨客户端运行占用锁不属于本次实现，其他客户端修改绑定不等同于当前浏览器立即换线。

## 已验证与边界

服务端使用临时 H2 验证换绑、解绑和编辑代理不修改指纹标识或设置；复制店铺生成独立标识。桌面回归覆盖地区响应解析、自定义优先、同一启动检测复用、取消及代理更换后身份文件与浏览数据保留。

`super-power-browser-desktop/scripts/fingerprint-native.test.cjs` 使用独立临时目录、两个本地代理和合成网页，对本机 Chromium 144 进行了四次有界面最小化启动。仅更换代理入口时，UA、CPU、Canvas、Audio、WebGL、ClientRects 与全部测试字体指标均稳定；更改语言与时区后，语言、请求头、Intl 时区和日期偏移正确变化，固定噪声与明确命名的 ASCII 字体指标保持稳定。

语言变化会影响部分通用字体及中日文缺字回退的测量值；恢复原语言后这些值恢复。因此固定 seed 不意味着切换语言后所有网页可见指纹都完全不变。

这组测试验证的是代理切换和当前原生内核参数语义，不是两个真实公网代理的端到端验收，也不证明旧闭源内核与新内核的 Canvas 等算法产生相同数值。旧版定位字段存在传参大小写和消费链路问题，本次未宣称或新增经纬度跟随 IP 能力。

复测：

```powershell
# 在 super-power-browser-desktop 下执行；路径指向要验收的指纹内核。
$env:SPB_FINGERPRINT_EXECUTABLE = 'D:\path\to\chrome.exe'
node --test scripts/proxy-locale.test.cjs scripts/browser-network.test.cjs scripts/fingerprint-native.test.cjs
```

未设置内核路径时，原生实测脚本跳过；其余测试不使用真实店铺数据。
