# 插件验证范围

## 本地检查

`npm run build` 生成两个内置插件及 ZIP。`npm run verify` 检查发布脚本语法、manifest、导入路径、页面和样式资源引用，并拒绝不符合服务地址要求的发布包。

构建检查不会执行真实平台登录、支付或供应商业务。

## 已验证的桌面链路

Windows x64 Chromium 144 的店铺启动、窗口显示、双插件加载、鉴权 WebSocket 连接、环境检查完成、重复打开复用和关闭回收已有实机验证。窗口闪烁和声音遵循客户端消息设置。

退出、重启、注销、取消启动和共享下载是分别处理的动作；客户端为单实例应用。

## 发布前需要验证

- 当前内核下的真实平台登录、账号填充规则、Passkey 注册及认证。
- 账号和店铺权限变更、会话过期、设备故障时的插件与桌面状态。
- 目标供应商线路、第三方插件目录、云端存储及网络服务。
- 生产 MySQL、HTTPS 部署和正式安装包。

Cookie、书签及 Passkey 同步不代表完整浏览数据云同步。公网出口检查与 TCP Ping 不代表供应商完整线路测速。

当前能力和待接入事项见 [功能说明](features.md) 与 [功能与部署状态](../../docs/功能与部署状态.md)。
